## 发现与闭环

| 独立发现 | 设计修订 | 最终判断 |
|---|---|---|
| 根 Process 的 TERM 与 task group 超时不能证明整个前置副作用结束 | 同版本原生监督、进程组身份、55 秒工作/5 秒清理、子预算、锁与副作用资格持有至确认结束 | 阶段 0 边界明确；阶段 1 必须验证 |
| 撤销暂时失败留下两条，下一次被歧义拒绝 | 可信事务精确续作、幂等请求/最终状态验证、未知或第三条规则禁止写 | B2 已实证缺口；设计承接明确 |
| 退出码合并认证、网络及歧义，无法正确暂停/恢复 | 内部结构化脱敏分类、unknown 保守重查、认证每资源 1800 秒只读重验证 | 不再承诺通过本地文件变化探测服务端权限恢复 |
| mkdir 锁异常退出后可能永久遗留 | 内核锁与受监督持有者寿命、可信遗留恢复、未知旧锁保留 | 阶段 1 有活锁/崩溃/身份冲突验证要求 |
| 初稿把 profile 纳入资源键，同一远端安全组可能分锁 | 资源键只用 region/security-group，profile 仅选择凭据；身份无法解析则更粗全局互斥 | 已修正，U11 覆盖不同 profile 同资源 |
| 新旧互斥如果先检查目录再执行会有竞争 | 新 supervisor 持新锁后还须原子 mkdir 持旧锁，失败释放新锁退避；禁止 check-then-act | 已修正，U11 覆盖新旧路径同时竞争 |

以上是同一设计复核过程中的观察与修订。初稿不具备放行条件；最终修订经同一独立复核者再次确认，未以主代理自验覆盖独立发现。
