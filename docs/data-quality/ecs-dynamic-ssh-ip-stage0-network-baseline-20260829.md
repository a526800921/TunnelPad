# ECS 动态 SSH 公网 IP 同步：阶段 0 公网出口基线

日期：2026-08-29
性质：本机公网 IPv4 探测基线；不是安全组写入、SSH 实连或完整网络路径证明。

## 范围与安全边界

- 探测显式禁用代理并强制 IPv4，仅访问两个 HTTPS 公网地址查询端点。
- 不调用阿里云 API，不读取凭证，不连接 ECS，不修改安全组或任何云端资源。
- 不记录原始公网 IPv4、账户或资源标识；只记录一致性结论和不可逆地址哈希。

## 样本结果

| 样本 | 动作 | 结果 | 结论 |
|---|---|---|---|
| 第一端点 | `curl --noproxy '*' -4` 请求 HTTPS 公网地址查询服务 | 返回合法全局 IPv4 | 通过。 |
| 第二端点 | 同样禁用代理、强制 IPv4 请求另一 HTTPS 地址查询服务 | 返回合法全局 IPv4 | 通过。 |
| 双源比对 | 比较两个响应并验证地址类型 | 两者相同；地址哈希为 `b6ad59297aa31858` | 当前本机直连出口基线通过。 |

## 限制与下一步

- 此结果不替代目标 SSH 实连，也不能证明目标 ECS 未通过其他安全组、主机防火墙或网络路径放行。
- 在任何安全组写入前，仍须确认目标网卡关联的全部安全组和 Workbench 恢复通道。
