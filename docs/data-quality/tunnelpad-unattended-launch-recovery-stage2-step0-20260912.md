## 执行矩阵

1. 使用正常 AppleScript quit 关闭旧 App，等待目标 label 未加载及 API 端口关闭，不以进程被杀代替正常退出。
2. 通过临时外部配置 source 原配置，再覆盖 CURL_BIN 与 ALIYUN_BIN。curl wrapper 在故障标记存在时返回网络错误并只记录时间；解除标记后调用真实 curl。aliyun wrapper 只允许 DescribeSecurityGroupAttribute，拒绝任何其它 action，避免验收引入真实写。wrapper 位于私有临时目录，原配置不改。
3. 启动同版 Release 新包；因 launch 工具无环境参数，此故障窗口直接启动包内可执行文件并注入单进程 TUNNELPAD_CONFIG_FILE。观察至少一次 300 秒退避（预计尝试 0/5/20/50/110/410 秒），API 每 10 秒读取脱敏 ID/status/PID/probe；记录 CPU time/RSS 和 app.log 字节增量，不能以短窗口断言全天能耗。
4. 在首个长退避验证后解除故障标记，不发 start/restart，不重启 App；最多 330 秒内 fresh PID running 与 probe satisfied，未勾选两条仍 not_loaded。确认成功后至少 40 秒无额外前置调用。
5. 正常退出，核对 API/label/监督子进程清理；再次故障启动，用既有 stop API 取消目标，解除故障后观察超过其下一次退避仍不自动启动；退出。
6. 最后仍以单进程配置启动独立新版包（去除 curl 故障，保留 ALIYUN_BIN 只读护栏），确认原唯一候选自动运行、其它未启动、配置哈希未变，保留旧包。

## 失败及回滚

任何未知状态、云端需要写入、非目标启动、配置变化或退出不收敛均停止验收并保留证据。不删除可信 journal/未知锁；若有未完成事务不回旧版本。确认无事务和监督进程后，可正常退出新包，再用同样单进程只读云护栏启动保留的旧包恢复原候选；旧包不兼容护栏或无法证明无写时保持停止并报告，不自动移除护栏。不得通过原始云输出解释错误或记录凭据。
